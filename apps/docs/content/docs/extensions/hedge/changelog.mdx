# vern-llm-hedge

## 0.1.0

### Minor Changes

- 8eb2e3d: First release of `vern-llm-hedge`, a middleware that cuts the slow tail of latency. When a call is slower than its target usually is, it sends the call to the next target too, keeps the first answer, and lets the core cancel the other. The delay is learned from the logger's `attemptMs` percentiles, and a token bucket keeps extra calls near 5% of eligible calls. `maxHedges`, `adapt` and `cacheAware` are opt in, and each call reports one `hedge.decision` event.

  ```ts
  import { VernLLM } from 'vern-llm';
  import { loggerMiddleware } from 'vern-llm-logger';
  import { hedgeDimension, hedgeMiddleware, promptSizeDimension } from 'vern-llm-hedge';

  const logger = loggerMiddleware({
    dimensions: { size: promptSizeDimension, hedge: hedgeDimension },
  });
  const hedge = hedgeMiddleware({ stats: logger.stats });

  const llm = new VernLLM({
    client,
    model: 'main',
    fallback: [{ client: backupClient, model: 'backup-model', name: 'backup' }],
    middleware: [logger, hedge],
  });
  ```

  A new package, so existing code keeps compiling and behaving the same at runtime. It never changes what a call returns or throws, and a call it cannot hedge runs as it would without it.
