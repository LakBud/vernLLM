---
title: API Reference Overview
description: The public exports of vern-llm-policy, and where each option and the decision are documented
---

| Export                    | Kind     | What it is                                                                                            |
| ------------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `policyMiddleware`        | Function | Takes `PolicyOptions` and returns one middleware with `evaluate()` and `update()`. Once per `VernLLM` |
| `policyMiddlewareRef`     | Constant | The `MiddlewareRef` of that entry, so a second one in the same `VernLLM` is rejected                  |
| `policyFlags`             | Function | Reads the flags a call's rules set, from any middleware inside policy                                 |
| `POLICY_DECISION_EVENT`   | Constant | `'policy.decision'`                                                                                   |
| `POLICY_CROSS_JOIN_EVENT` | Constant | `'policy.cross_join'`                                                                                 |
| `PolicyOptions`           | Type     | Every option, see [Configuration](/docs/extensions/policy/API-reference/configuration)                |
| `Decision`                | Type     | What a decision holds, see [Decision](/docs/extensions/policy/API-reference/decision)                 |

```ts title="policy-exports.ts"
import {
  policyMiddleware,
  policyMiddlewareRef,
  policyFlags,
  POLICY_DECISION_EVENT,
  POLICY_CROSS_JOIN_EVENT,
} from 'vern-llm-policy';
import type {
  PolicyMiddleware,
  PolicyOptions,
  PolicyRule,

  Pattern,

  Decision,

  EvaluateInput,
  EvaluateTarget,
} from 'vern-llm-policy';
```
