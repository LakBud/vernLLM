title: Configuration
description: Every routerMiddleware option with its type and default, the route options, and what throws at construction.
---

Every option is optional. `routerMiddleware()` with no routes leaves every order as it is. A bad
option throws a plain `Error` prefixed `routerMiddleware:` at construction, never during a call.

## Construction errors

| Mistake                                        | Result |
| ---------------------------------------------- | ------ |
| A route without a name, or two with one name   | Throws |
| A `when`-less route that is not last           | Throws |
| A `when` object with a wrong shape             | Throws |
| `exclude` removing every target a route lists  | Throws |
| A target listed twice, or `'*'` sharing a tier | Throws |
| A strategy that needs `stats` or `cost` unset  | Throws |
| A non positive `contextWindow`                 | Throws |
