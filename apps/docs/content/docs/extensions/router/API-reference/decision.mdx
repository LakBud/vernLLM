## Decision

```ts title="decision.ts"
interface Decision {
  route?: string;
  strategy: 'ordered' | 'weighted' | 'least-busy' | 'rank' | 'pinned';
  order: string[];
  excluded: { target: string; reason: 'route' | 'capability' }[];
  demoted: {
    target: string;
    reason: 'open' | 'limited' | 'over_limit' | 'over_deadline' | 'warming';
  }[];
  scores?: Record<string, number>;
  explored: boolean;
}
```

`scores` appears for `rank` only, rounded to two decimals, lower is better.

## RouterDecisionEvent

The event `router.decision` is a `Decision` plus `v: 1` and `applied`. See
[Observability](/docs/extensions/router/features/observability).
