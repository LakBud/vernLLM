---
title: Entries
description: Every field of the call, summary, error group, and breaker entries that vern-llm-logger writes to a sink.
---

A sink receives one of four entries, told apart by `kind`. Every entry carries `v: 1`. Fields that do
not apply are left out of the entry, never written as `null` or `undefined`.

```ts title="log-entry.ts"
type LogEntry = CallLogRecord | SummaryEntry | ErrorGroupEntry | BreakerEntry;
```

## Summary entry

`kind: 'summary'`, one per live series, written when `summary` is set. See
[Rolling Stats](/docs/extensions/logger/features/stats#periodic-summaries).

<TypeTable
  type={{
    series: {
      description:
        'metric, dimensions, count, quantiles keyed by quantile as a string, and the errors, rejections, aborts, and cacheHits counters.',
      type: 'SeriesSnapshot',
      required: true,
    },
    exemplar: {
      description:
        'On the durationMs series only: the slowest call in the window, with its requestId and durationMs.',
      type: '{ requestId: string; durationMs: number; fields?: Record<string, JsonValue> }',
    },
  }}
/>

## Error group entry

`kind: 'error_group'`, written when an error window closes. See
[Error groups](/docs/extensions/logger/features/detection#error-groups).

<TypeTable

    },

      required: true,

      description: 'The first error of the window.',
      type: 'string',
      required: true,

    lastRequestId: {
      description: 'The last error counted.',
      type: 'string',
      required: true,
    },
  }}
/>

## Breaker entry

`kind: 'breaker'`, written for a circuit breaker change outside any call. See
[Circuit breaker changes](/docs/extensions/logger/features/detection#circuit-breaker-changes).

<TypeTable
  type={{
    provider: {
      description: 'The target whose breaker changed.',
      type: 'string',
      required: true,
    },
    model: {
      description: 'The model of that target.',
      type: 'string',
      required: true,
    },
    from: {
      description: 'The previous state.',
      type: "'closed' | 'open' | 'half-open'",
      required: true,
    },
    to: {
      description:
        'The new state. An entry is written at warn when this is open, otherwise at info.',
      type: "'closed' | 'open' | 'half-open'",
      required: true,
    },
    consecutiveFailures: {
      description: 'The failure count when the state changed.',
      type: 'number',
      required: true,
    },
  }}
/>
