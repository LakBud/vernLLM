---
title: Logger Overview
description: One structured record per call, rolling latency percentiles, and slow call and error detection for every VernLLM call
---

`vern-llm-logger` is one middleware that writes a structured record for every call. It keeps
rolling latency percentiles per provider and model, marks slow calls, groups repeated errors,
samples plain successes, and writes periodic summaries. Retries, fallbacks, rate limit waits, cache
hits, and circuit breaker changes all land in the record, with no change to how you call VernLLM.

<Callout type="info">
  A failure inside the logger never changes a call. Prompt text, output text, and error messages are
  never recorded, only the error `type`, `code`, and `status`. For traces, metrics, and opt in
  content capture, use the [OpenTelemetry integration](/docs/integrations/otel).
</Callout>

`vern-llm` is a peer dependency, so the package shares the copy your app already uses, and it has
no other dependency. It needs a `vern-llm` release that includes `CallResult.cache`, which is how it
tells a cache hit from a shared in flight call.

## Basic usage

```ts title="logger-basic-usage.ts"
import OpenAI from 'openai';
import { VernLLM } from 'vern-llm';
import { jsonSink, loggerMiddleware } from 'vern-llm-logger';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

const logger = loggerMiddleware({ sink: jsonSink() });

const llm = new VernLLM({
  client: openai,
  model: 'gpt-4o',
  middleware: [logger],
});
```

Every call now writes one line of JSON to `console.log`. Pass `consoleSink()` for a readable line
in a terminal, or any object with a `write(level, entry)` method to send entries anywhere else, see
[Sinks](/docs/extensions/logger/features/sinks).

Register the middleware once per `VernLLM`: two entries in one `middleware` array throw at
construction. One `loggerMiddleware()` object can serve several `VernLLM` instances, and they then
share its stats.

Call `dispose()` on shutdown. It stops the timer and writes any error groups still pending:

```ts title="logger-dispose.ts"
process.on('SIGTERM', () => {
  logger.dispose();
});
```
