# vern-llm-usage

## 0.1.0

### Minor Changes

- 6067f14: Introducing `vern-llm-usage`: estimated cost, wasted spend and budgets for vern-llm calls, built only on its public middleware system. It prices every call from a dated table you supply, or uses the cost the provider reports, and rejects a call that would go over a dollar or token budget before any provider is contacted, as `quota_exceeded` with code `budget_exceeded`. Cache hits and joins report `estimatedSavedUsd`. For calls that run more than one chain, `unkeptUsd` is the spend of chains whose answer was not returned.

  ```ts
  import { VernLLM } from 'vern-llm';
  import { usageMiddleware } from 'vern-llm-usage';

  const usage = usageMiddleware({
    prices: { 'gpt-6-sol': { input: 1.25, output: 10 } }, // dollars per 1M tokens
    pricesAsOf: '2026-10-01',
    attribute: ['tenantId'],
    budgets: [{ key: 'tenantId', limitUsd: 50, per: 'day' }],
  });
  const llm = new VernLLM({ client, model: 'gpt-6-sol', middleware: [usage] });

  usage.totals({ tenantId: 'acme' }); // includes estimatedCostUsd and unkeptUsd
  await usage.remaining({ tenantId: 'acme' });
  ```

  A new package, so existing code keeps compiling and behaving the same at runtime. It needs the vern-llm release that adds the `budget_exceeded` code.
